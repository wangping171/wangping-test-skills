# Greeting Helper

## Overview

Create a concise greeting that matches the requested audience and tone. Keep the result ready to copy and avoid adding explanations unless the user asks for options or reasoning.

## Workflow

1. Identify the recipient or audience, occasion, channel, and requested tone.
2. Infer a neutral, polite tone when the user does not specify one.
3. Adapt the wording to the communication channel.
4. Write one polished greeting in one or two sentences.
5. Offer up to three alternatives only when the user requests choices.

## Output Rules

- Address the intended audience directly when enough context is available.
- Match the requested language and formality.
- Avoid invented names, dates, achievements, or personal details.
- Keep a greeting under 40 words unless the user requests a longer message.
- Return the greeting directly without a label such as "Greeting:" unless requested.

## Tone Presets

- Formal: Use respectful wording and avoid slang.
- Warm: Add a sincere, personal touch while staying concise.
- Casual: Use natural conversational wording appropriate for chat.
- Playful: Add light humor only when the occasion and audience make it appropriate.

## Channel Templates

- Team chat: Use a direct, conversational opening.
- Email: Add a polite opening and a natural closing when appropriate.
- Announcement: Make the key occasion clear in the first sentence.
- Card: Prefer a warm, memorable one- or two-sentence message.

## Example

For a request to welcome a new teammate in a team chat, write:

> Welcome to the team! We are excited to have you with us and look forward to working together.
